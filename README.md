# ProtoELN

A prototype web-based Electronic Lab Notebook (ELN): a living lab notebook and scientific data forge for experiment write-ups, pasted tables and JSON results, instrument files, revision history and signing.

ProtoELN is a companion project to [ProtoLIMS](https://github.com/leehart3000/protolims).
